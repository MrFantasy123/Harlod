# HARLOD (HARLOD)

**The Aspiring Meme Token – Community Take Over (CTO)**

HARLOD is a community-driven meme token launched on **August 30, 2025** via [Pump.fun](https://pump.fun).  
After the original developer abandoned the project, the community initiated a **CTO (Community Take Over)** on **September 5, 2025**.  
Since then, HARLOD has been fully managed by its community with a single mission:  
👉 **“Become a Meme.”**
